# 方案 B：「Warm Card」— 温暖卡片/杂志风格

**灵感来源：** Notion · Apple Notes · Headspace · Linear

---

## 设计哲学

学习不是写代码，是一段旅程。用温暖的色调、大卡片、充足留白营造"坐下来翻开一本书"的感觉。信息分层展示，每次只关注一件事。卡片是信息的自然容器，圆角和柔和阴影让界面有"呼吸感"。

---

## 关键组件设计

### 1. Hero Streak 卡片

```
宽度：100%，最大 640px
居中：margin: 0 auto
圆角：16px
背景：白色 #ffffff
阴影：0 2px 16px rgba(0,0,0,0.06)
内边距：32px

内容（从上到下）：
  🔥 火焰 emoji（32px）
  大号数字 "12"（48px, font-weight: 700）
  小字 "day streak"（13px, 次文字色）
  鼓励文案 "你已经连续学习了 12 天"（14px）
  SVG 圆形进度环（半径 40px, 描边宽度 6px, 颜色 #4a9e6e）
  "45/137 · 32.8%"
```

### 2. 阶段卡片

```
背景：白色 #ffffff
圆角：12px
阴影：0 1px 4px rgba(0,0,0,0.04)
边框：1px solid #e8e5df
内边距：20px
间距：16px（卡片之间）

卡片头：
  左：阶段名（14px, 加粗）
  右：完成计数标签（小圆角 pill, 背景 #f5f3ef）

卡片体：
  迷你日格子行——横向排列，8×8px 小方块
  Section 名——11px 小字，颜色 #8c8c8c，逗号分隔
```

### 3. 迷你 KPI 卡片

```
宽度：1fr（等分）
圆角：10px
背景：白色 #ffffff
阴影：0 1px 4px rgba(0,0,0,0.04)
内边距：16px
居中文字

内容：
  emoji 图标（14px）
  数字（24px, 加粗）
  标签文字（11px, #8c8c8c）
```

### 4. Track 切换 Pill

```
位置：底部固定或顶部右侧
样式：两个并排的圆角胶囊
  未选中：背景 transparent, 文字 #8c8c8c
  选中：背景 #1a1a1a, 文字 #ffffff（黑底白字）
  或：选中 = 柔绿底 + 深绿字
圆角：20px
内边距：6px 16px
字体：12px
```

### 5. 日格子（迷你版）

```
正方形：10px × 10px（阶段卡片内的迷你版本）
圆角：2px
间距：3px
颜色：5 级绿（见配色方案）
无文字：纯色块
hover：轻微放大 + tooltip
```

### 详情页要点

- **全内容居中**：max-width: 640px, margin: 0 auto
- **大标题**：20px，居中，font-weight: 700
- **任务列表**：自定义圆形 radio 样式（不用原生 checkbox）
  - 空心圆 ○ = 未完成
  - 填充绿圆 ● = 已完成
  - 完成项文字删除线 + 变灰
- **Prompt 默认折叠**：点击展开，减少初次加载的视觉压力
  - 折叠状态显示 "学习指引 — 展开 ▼"
  - 展开后显示完整 Prompt + Copy 按钮
- **返回链接**：顶部居中，小字，箭头图标
- **导航按钮**：底部居中，两个大间距按钮 + Home 链接

## 字体系统

```
--font: -apple-system, BlinkMacSystemFont, "Segoe UI", "Noto Sans", "PingFang SC", "Microsoft YaHei", sans-serif
（中文友好优先）

用法：
- 大标题（Hero 数字）→ font-weight: 700, letter-spacing: -0.02em
- 阶段卡片标题 → font-weight: 600, 14px
- 正文描述 → font-weight: 400, 14px, line-height: 1.8
- 数字 → font-weight: 600, font-feature-settings: "tnum"（等宽数字）
- 小标签 → font-weight: 500, 11px, uppercase, letter-spacing: 0.05em
```

## 响应式行为

```
> 768px：
  - 阶段卡片 2 列 grid
  - Hero 卡片完整显示
  - 详情页 640px 宽居中

< 768px：
  - 阶段卡片 1 列
  - Hero 缩小（32px 数字）
  - 迷你 KPI 3 列保留但缩小

< 480px：
  - 迷你 KPI 变为横向滚动
  - 详情页 padding 减少
  - 导航按钮缩小
```

## 动画/过渡

```
- 阶段卡片 hover：上浮 2px + 阴影加深，过渡 0.2s ease
- 任务圆点填充：0.3s ease-in-out，带缩放回弹
- Prompt 折叠/展开：max-height 过渡 0.3s
- 复选框点击：scale(1.2) → scale(1) 回弹
- 页面切换：淡入淡出 0.2s
- Streak 数字变化：CSS counter 动画或过渡
```
