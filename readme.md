# 量化 + AI 双轨学习计划

> 一个持续调整的个人学习计划：用主线学习构建与判断，用数学理解工具背后的原理，并在实践中巩固。

## 项目介绍

我用这个仓库维护学习路线、每日目标和进度页面。课程从 Python 与数据处理出发，逐步进入金融基础、AI 应用、策略研究、服务部署与 Agent。

学习的目标是形成独立拆解问题、组织构建和评价结果的能力。AI 可以协助实现；问题怎么定义、方法是否合适、结果能说明什么，由我负责。

## 我的学习方法

1. 从计划中明确当天的主要问题、已有基础和范围。
2. 用 teach skill 根据当天上下文生成实践任务与验收标准。
3. 在实践中调用知识，遇到卡点再补充必要理解。
4. 结合自己的分析、解释和反馈修正结论，完成后记录进度。

两条轨道各按每天约 3 小时设计，独立推进。plan 负责目标、概念、衔接与边界，具体练习和验收由当天教学生成；部分已学内容仍保留历史任务文本。

数学 M50–M61 采用应用巩固：每天一个主要问题，不固定新概念或实验数量。验收关注我自己的选择、分析与解释，笔记可以简短；只有 AI 生成的代码或图表不能证明掌握。主线继续沿用原教学验收方式。

## 使用方法

### 启动学习计划

需要 Python 3.7+，不需要安装第三方依赖或执行前端构建。

- Mac：双击 `启动学习计划.command`。
- Windows：双击 `启动学习计划.bat`。

也可以从仓库根目录运行：

```bash
python3 tools/plan_server.py
```

服务会打开浏览器。需要指定端口或关闭自动打开时，可查看：

```bash
python3 tools/plan_server.py --help
```

### 浏览课程与记录进度

在页面选择主线或数学，进入当天内容。主线 D87–144 与数学 M50–61 不预置任务清单，使用“标记本日已完成”记录状态；它不代替教学中的验收。

启动器运行时，进度保存在 `progress/current.json`，历史快照在 `progress/history/`。直接打开网页文件会使用浏览器本地存储；可查看页面连接状态确认保存位置。

进度文件不随 Git 同步。使用同一个服务时，避免多台设备同时修改；备份、旧进度迁移及连接问题见[本地运行与进度维护](docs/本地运行与进度.md)。
