# 双轨 · 个人学习计划 UI Demo

一个独立、无需构建的静态工具，位于 `~/stu/plan/demo/`。没有后端、登录或真实同步。不会读取或修改正式学习计划。

## 运行

直接用浏览器打开 `demo/index.html`，全部页面和本地字体均可离线运行。也可以在终端启动：

```sh
cd "$HOME/stu/plan/demo"
python3 -m http.server 4173 --bind 127.0.0.1
```

随后访问 `http://127.0.0.1:4173/`。如果端口被占用，将 `4173` 改为其他端口。HTTP 与直接文件打开可能使用不同的本地存储空间。

## 设计与任务流

采用暗色 **True-black flat**（design-taste-frontend，seed **680993631**，保留既有本地 Geist 字体）。全黑底面以深灰层级区分工作区和内容区，反白按钮承载主操作，黄绿色只用于进度、当前学习日和完成状态。视觉重点是下一项学习内容，而不是总数。原抽签 home 模式的四个统计卡改为任务优先的组合，因为它不符合本工具的使用目的。

| 界面 | 首要问题 | 常用操作 | 主要数据 |
| --- | --- | --- | --- |
| 今日学习 | 我现在应该学什么？ | 继续学习、切换轨道、定位学习日 | 下一学习日、当前任务、双轨完成比例、阶段、近期完成、连续天数 |
| 学习日 | 今天做什么，我做完了吗？ | 勾选任务、标记当天完成、阅读或复制 Prompt、进入关联数学、前后日导航 | 编号、阶段、小节、目标、时长、概念、Prompt、任务与关联 |
| 课程目录 | 我的两条学习路径如何组织、目标内容在哪里？ | 查看思维导图、打开任一学习日、从阶段进入列表浏览、标题或编号搜索、按状态筛选 | 两轨阶段—小节—学习日结构与完成状态 |

侧栏中的“课程目录”打开独立的课程大纲界面。该界面参考原学习空间的课程大纲，以双轨根节点、阶段、小节和学习日的连线层级来表达路径；节点显示学习日范围、完成数与当前学习日。点击学习日直接进入学习，点击阶段可在列表目录中定位。详情为阅读区和固定任务栏。平板将主导航折叠至顶部；手机将两轨重排为纵向路径、学习日改为单列，页面本身不横向滚动。

## 可以试的路径

- `#home/main`：主计划首页，继续第 78 天。
- `#day/main/78`：正常学习，默认已完成 1/4 项任务；勾选其余任务后可标记当天完成。
- `#day/main/79`：尚未开始。
- `#day/main/77`：已经完成，可以重新学习。
- `#day/math/34`：Embedding 的数学，支持返回关联主计划。
- `#courses/main`：搜索 `34` 会跨阶段定位第 34 天；关键词搜索、状态筛选和空结果也可演示。
- 导航下方“演示数据与状态”：重置为正常学习、尚未开始或全部完成。

状态自动保存到当前浏览器 `localStorage`，使用独立键 `dual-track-ui-demo-v1`。勾完任务不会自动完成学习日，需明确点击完成按钮；取消任意任务会撤销当天完成状态。连续学习天数以至少完成一个学习日的自然日计算；今天未完成时允许截至昨天的连续记录。无需将另一轨也做完。

## 数据与迁移

`js/data.js` 是唯一课程来源；`js/app.js` 包含状态计算、存储、路由、渲染与事件处理；`css/app.css` 包含设计变量和响应式规则。没有外部运行依赖。

演示有主计划 96 天／4 阶段／8 小节、数学 42 天／3 阶段／6 小节。默认完成 77 天与 33 天、连续 6 天。日期固定 **2026-10-29**。所有比率、阶段计数、近期完成和状态均从记录计算，未另写一份统计数值。

正式接入时替换：

1. 课程阶段、小节、标题、目标、建议时长、概念、Prompt 与任务（当前大部分非重点学习日的教学内容由统一模板生成）。
2. 主计划与数学的关联表（当前重点演示主 78 ↔ 数学 34）。
3. 初始勾选与完成日期，以及固定演示时钟和演示状态入口。
4. `save()` 与读取本地记录的实现，接入正式持久化；保留每个学习日的稳定 ID。当前模拟编号连续，正式课程可能有跳号，前后日应继续按数组顺序导航。
5. 若正式任务会调整数量，为任务设置稳定 ID，再迁移当前按数组下标保存的勾选状态。

当前没有真实计时、实际大模型调用或跨设备同步。显示的分钟数是建议学习时长。
