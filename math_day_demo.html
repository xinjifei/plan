=== Math Day 27：向量点积——相似度的数学根源 ===

【每日学习时长】约25分钟

【与主计划的关联】
你今天在 Main Day 42 正在学：Embedding 向量检索——用 ChromaDB 做语义相似搜索。
当你写下 collection.query(query_embeddings=[...]) 时，ChromaDB 内部就在做「查询向量与库存向量的余弦相似度计算」。
今天这 25 分钟数学，就是让你看清楚那一行代码背后到底发生了什么。
关联度：对 AI 开发直觉 ★★★ / 对量化实践 ★

【学习目的】
建立「点积 = 方向一致性度量」的核心直觉。两个向量点积越大，方向越一致；点积为 0，互相垂直；点积为负，方向相反。把点积除以两个向量的长度之积，就得到余弦相似度 ∈ [−1, +1]。这就是所有向量检索（RAG、推荐系统、语义搜索）的数学引擎。不理解点积，Embedding 检索对你来说就是黑盒。

【学习标准】
- 能口述：点积公式 v·w = v₁w₁ + v₂w₂ = |v||w|cos(θ)，每一项的几何含义
- 能写代码计算两个给定向量的余弦相似度
- 能解释：为什么余弦相似度比欧氏距离更适合比较文本语义？
- 能画图说明：两个向量夹角 0°/90°/180° 时，余弦相似度分别接近 1/0/−1

【学习难度】
初中数学基础 → 大学一年级线性代数直觉
前置知识：向量是什么（Day 24）、向量加减法（Day 25）
不需要理解证明，只需要理解几何含义

【所需工具】
Python 3.x + numpy + matplotlib

【核心概念】
- 点积（Dot Product）v·w = v₁w₁ + v₂w₂ + ... = |v| × |w| × cos(θ)
- 方向一致（θ=0°）→ cos=1 → 点积最大
- 垂直（θ=90°）→ cos=0 → 点积为 0
- 方向相反（θ=180°）→ cos=−1 → 点积最小（负值）
- 余弦相似度 = (v·w) / (|v| × |w|) ∈ [−1, +1]

【练习任务】
- 定义 v1=[1,2], v2=[2,4], v3=[−2,1]，手算 v1·v2 和 v1·v3
- 写 cosine_sim(a,b) 函数，验证 v1 和 v2 相似度≈1，v1 和 v3≈0
- 画三个向量，标注两两之间的夹角和余弦相似度
- 思考：两篇文章的 Embedding 余弦相似度=0.95 说明什么？=0.02 说明什么？
