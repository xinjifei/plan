# 认知科学视角：当前学习计划的问题诊断

> 2026-06-16 · 基于 2023-2025 年已发表研究，非 AI 训练数据推断

---

## 研究方法

搜索了以下方向的 2023-2025 年研究文献：
- Spaced repetition & interleaving (Lafleur & Kanazawa 2024; IEEE 2024)
- Productive failure (Kapur 2014-2025, 160+ 实验对比)
- Desirable difficulties (Bjork Lab, UCLA)
- Forgetting curve & optimal review intervals (Wu et al., 2024)
- Cognitive fatigue & optimal session length (EEG 研究, 2024; Pomodoro 元分析, 2025)
- Dual coding theory (Paivio; Mayer)

---

## 发现一：间隔重复机制缺失（严重）

### 研究告诉我们什么

Ebbinghaus 遗忘曲线：**1 小时内遗忘 >50%，1-2 天内遗忘 ~70%**。Bjork 的 spacing effect：分散学习比集中学习的长期保留率高 2-3 倍。Wu et al. (2024) 将 ACT-R 认知架构与遗忘曲线结合，证明自适应间隔排程比固定间隔更有效。

### 当前计划的缺陷

用户在同一天接触一个概念两次（Main 3h + Math 25min），但之后**零系统化复习**。举个具体例子：

```
Day 48: Main 学 Bootstrap（工具化） + Math 学方差（原理化）
        ↓
        此后 Bootstrap 再也没有在 Main 或 Math 中出现
        直到 Math Day 49（日历第 87 天）才再次遇到
        ↓
        间隔 39 天 → 遗忘曲线预测：几乎全部遗忘
```

**两个轨道各讲一遍 ≠ 间隔重复。** 真正的间隔重复要求在 1 天、1 周、1 个月等关键节点主动提取。当前计划完全没有这个机制。

---

## 发现二：Main 轨道 3 小时连续学习违反认知负荷理论（中等）

### 研究告诉我们什么

2024 年 EEG 研究：**最有效注意力持续约 19 分钟，43 分钟触发显著脑力疲劳。** 2025 年 BMC Medical Education 发表的 Pomodoro 元分析（32 项研究，5270 人）：系统化分段（24min 工作 + 6min 休息）比自主安排疲劳减少 ~20%，专注度提升 15-25%。

### 当前计划的缺陷

```
当前：3 小时连续 Main 学习，无结构化分段
      + 25 分钟 Math（这个长度刚好是最优的）

研究建议：每 25 分钟穿插 5 分钟休息
          每 2 个 25 分钟段穿插 15 分钟长休息
```

Math 轨道的 25 分钟恰好是研究验证的最优长度。Main 轨道的 3 小时需要内置分段。

---

## 发现三：提取练习（Testing Effect）缺失（严重）

### 研究告诉我们什么

Roediger & Karpicke (2004)——学习科学中被引用最多的实验之一：
- 重复学习组：5 分钟后 83%，**1 周后 40%**
- 提取练习组：5 分钟后 71%，**1 周后 61%**
- 提取练习的长期遗忘率远低于重复学习

Bjork：**"测试不是评估工具，是学习工具。"**

### 当前计划的缺陷

每日 task checkbox 是「完成标记」，不是「提取练习」。没有任何机制要求用户在学新内容前先回忆旧内容。没有每日/每周的快速自测。

---

## 发现四：Productive Failure 模型验证了「先工具后原理」，但缺少第三步（中等）

### 研究告诉我们什么

Kapur (2014, Cognitive Science)：九年级学生学标准差：
- 先解题再听课 vs 先听课再解题
- 程序性知识：无差异（9.24 vs 9.47）
- **概念理解：PF 组 2 倍优势（6.33 vs 3.84, d=2.00）**
- **迁移能力：PF 组近 2 倍（5.37 vs 3.11, d=1.52）**

Kapur (2023, npj Science of Learning)：PF 对所有学业基础的学生都有效。

PF 的三步模型：
```
1. 先尝试解决（生成自己的解法）→ 激活已有知识
2. 接受正式教学 → 意识到自己的解法哪里不够好
3. 对比&整合 → 深层编码
```

### 当前计划的缺陷

当前计划实现了前两步：
```
第 1 步 ✓: Main 轨道先给工具用（"把数据扔给 Bootstrap，看 p 值"）
第 2 步 ✓: Math 轨道后给原理（"Bootstrap 归零重抽样的数学直觉"）
第 3 步 ✗: 没有任何环节要求用户对比「Main 时的理解」和「Math 时的理解」
```

缺少第三步的对比/整合，PF 效应只发挥了一半。

## 发现五：交错练习（Interleaving）完全缺失（中等）

### 研究告诉我们什么

Kornell & Bjork (2008)：学习者识别画家风格——交错组练习时表现更差但最终测试显著更好。关键：**学习者始终认为集中练习更有效——即使自己的测试成绩已经证明了相反。**

2024 年 npj Science of Learning 研究：教学生自我调节交错练习，**每次类别切换增加正确率 4-5%**，且效果在 5-7 天后仍然存在。

### 当前计划的缺陷

每天一个主题，完全集中式（blocked）：

```
Main Day 46: 方差（只有方差）
Main Day 47: 协方差/相关性（只有协方差）
Main Day 48: Bootstrap（只有 Bootstrap）
```

从无「对比方差 vs 协方差 vs Bootstrap 三种工具分别解决什么问题」的交错练习。用户可能单独理解每个概念，但不清楚它们之间的区别——而「区别」恰恰是深层理解的关键。

---

## 发现六：Math 轨道「提前太多」导致遗忘（严重）

### 研究告诉我们什么

遗忘曲线 + spacing effect：间隔越长，保留越低。最佳首次复习间隔约 1 天。如果间隔超过 2-4 周且没有中间复习，相当于重新学。

### 当前计划的缺陷

```
Math Day 23 (过拟合) 在日历第 61 天教
Main Day 84 才用到 → 间隔 23 天 → 无中间复习 → 大量遗忘

Math Day 28 (矩阵) 在日历第 66 天教
Main Day 79 才用到 → 间隔 13 天 → 部分遗忘

Math Day 45 (Sharpe) 在日历第 83 天教
Main Day 95 才用到 → 间隔 12 天 → 部分遗忘
```

当 Math 提前 Main 两周以上教学时，没有中间复习机制来对抗遗忘曲线。

---

## 发现七：Dual Coding 未充分利用（轻微）

### 研究告诉我们什么

Paivio 双编码理论：具体 + 抽象双重编码 > 单一编码。Mayer 多媒体学习理论：视觉 + 语言同步呈现促进迁移（对高空间能力学习者尤其有效）。

### 当前计划的缺陷

Main 轨道大量用代码和图（视觉编码），Math 轨道大量用公式和推导（语言编码）。两者是分开的——没有在同一个概念的两次接触中显式建立「这张图 ≈ 那个公式」的联结。

## 最低成本修复方案

### 1. Main 轨道加入每日 2 分钟「快速回顾」（修复 #1、#2）

每天 Main 学习开始前，回答两个问题：
- 「昨天学的工具叫什么？输入什么？输出什么？」
- 「它和我前天学的工具有什么不同？」

成本：2 分钟/天。研究基础：testing effect + spacing。

### 2. Main 轨道 3 小时分为 25 分钟段（修复 #4）

```
25min 学习 → 5min 休息 → 25min 学习 → 5min 休息 → ...
共 6 个学习段 ≈ 3 小时
```

成本：改变习惯，不改变内容。研究基础：EEG 研究 + Pomodoro 元分析。

### 3. Main 轨道每 6-7 天加一个「交错复习日」（修复 #5、#6）

把最近一周学的 2-3 个工具混在一起出一个小练习（如「给同样一组数据，分别用方差、协方差、Bootstrap 分析，对比结论」）。

成本：占用一个缓冲日。研究基础：interleaving effect。

### 4. Math 轨道在概念被 Main 用到时激活「快速提醒」（修复 #3）

Math 轨道检测到某个概念对应的 Main Day 到了，在当天的 Math prompt 中加入一行：「注：你的 Main 轨道今天在用 [概念名] 了——回想一下 Math Day X 讲的直觉。」

成本：改 sync 脚本加一行逻辑。研究基础：spacing + contextual interference。

### 5. Math 轨道加「对比反思」（修复 #5）

在 Math 轨道讲到 Main 已经用过的概念时，加入一个反思提示：「你在 Main Day X 已经用过 [概念名] 了。当时你是怎么理解的？现在学了原理，你的理解和当时有什么不同？」

成本：在每个 Math Day prompt 的 `【练习任务】` 中增加一条。研究基础：PF consolidation phase。
