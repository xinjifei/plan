# 方案 A：「Developer Dark」— 终端/IDE 风格

**灵感来源：** VS Code · Linear · GitHub Dark · Obsidian

---

## 设计哲学

开发者用的工具，天然就该长得像开发者熟悉的环境。信息密度适中，一切可快速扫描，用代码编辑器式的视觉语言降低认知负担。左侧树形导航 + 右侧内容区，与 VS Code 文件浏览器一脉相承。

---

## 关键组件设计

### 1. 顶栏（Topbar）

```
高度：36px（比现在的 ~41px 更窄）
左：标题 "量化学习计划追踪" + 副标题
中：极细进度条（2px），内嵌在顶栏底部
右：Track 切换 tabs + Streak 数字
    用等宽字体显示数字：Day 45/137 | Streak: 12
```

### 2. 左侧树形导航（Sidebar）

```
- 固定宽度 220px，可折叠到 40px（仅图标）
- 每行：▶/▼ 箭头 + 阶段名 + 完成计数
- 当前激活阶段高亮背景（#21262d）
- 展开阶段显示 Section 子列表（缩进 16px）
- Section 点击 → 右侧滚动到对应位置
- Hover：背景变为 #21262d
- 滚动：Sidebar 自己滚动，不随主区域
```

### 3. 日格子（Day Cell）

```
正方形：16px × 16px（vs 原来的 26×14 长方形）
间距：3px gap
圆角：2px
无文字：纯色块，hover 时 tooltip 显示 "Day 23: 标题"
当前天（今天该做的）：边框高亮（蓝色 outline）
点击：进入详情页
```

### 4. Section 标题

```
样式：11px uppercase，颜色 #8b949e
布局：文字 + 右侧延伸线（::after 伪元素，1px solid #30363d）
与 VS Code 的 CodeLens 风格一致
```

### 5. 进度指示

```
顶栏内嵌进度条：2px 高，背景 #21262d，填充 #3fb950
无圆角或极小圆角
数字用等宽字体（font-family: var(--mono)）
```

### 详情页要点

- **Prompt 区域**：代码块风格，深色背景 `#161b22`，左边框 2px 蓝色强调线，类似 Markdown 代码块
- **Copy 按钮**：在 Prompt 区块右上角，小字，icon+文字
- **任务列表**：用系统原生 checkbox，`accent-color: #3fb950`
- **完成项**：`text-decoration: line-through` + `opacity: 0.5`
- **底部状态栏**：类似 VS Code 状态栏，固定在底部或跟随内容

## 字体系统

```
--font: -apple-system, BlinkMacSystemFont, "Segoe UI", "Noto Sans", Helvetica, Arial, sans-serif
--mono: "JetBrains Mono", "Fira Code", "Cascadia Code", ui-monospace, SFMono-Regular, monospace

用法：
- 标题、阶段名、Section 名 → var(--font)，sans-serif
- 数字（进度、streak、日期、格子编号）→ var(--mono)
- Prompt 内容 → var(--font)，13px（易读优先）
```

## 响应式行为

```
> 768px：Sidebar 可见，双栏布局
< 768px：Sidebar 隐藏，顶部汉堡菜单展开
< 480px：格子缩小到 12×12px，减少间距
```

---

## 动画/过渡

```
- 阶段展开/折叠：箭头旋转 0.2s + body 高度过渡 0.2s
- 格子 hover：outline 2px #58a6ff，outline-offset 2px
- 格子 click：scale(0.85) 0.1s
- 页面切换：opacity 0.15s（保持现有）
- Toast：上滑 + 淡入 0.2s
- 复选框：accent-color 立即切换，无延迟
```

## 特殊交互

| 交互 | 行为 |
|------|------|
| 键盘导航 | `j`/`k` 上一个/下一个 Day，`h`/`l` 或 `←`/`→` 切换，`Esc` 回 Home |
| 右键格子 | 上下文菜单：标记完成 / 取消完成 / 打开详情 |
| Sidebar 拖拽 | 可调整 Sidebar 宽度（通过拖拽右边界） |
| 双击顶栏 | 回到顶部 / 回到当天 |
