# 方案 C：「Dashboard」— 数据仪表盘风格

**灵感来源：** Strava · Apple Health · Coursera · 量化交易终端

---

## 设计哲学

你是量化交易学习者——用"分析你自己"的视角来看学习数据。把学习进度当成投资组合来追踪：有 KPI 指标卡、有趋势热力图、有完成率仪表盘。冷静、专业、数据驱动。界面长得很像你未来每天会用的量化看板。

## 关键组件设计

### 1. KPI 指标卡片

```
每个卡片 = 1 个核心指标
宽度：等分（flex: 1）
背景：#131726
边框：1px solid #1e2238
圆角：8px
内边距：12px 16px

卡片内容：
  顶部 emoji/icon（12px）+ 标签文字（10px, uppercase, #7c8299）
  中间大数字（28px, font-weight: 700, #e4e8f1）
  底部趋势文字（11px, #4e5466）

5 个 KPI：
  1. 🔥 Streak：当前连胜天数
  2. 📊 完成率：total done / total × 100%
  3. 📅 本周学习：本周有学习记录的天数
  4. ✅ 今日任务：今天需要完成的 task 数
  5. 📈 较上周：本周 vs 上周学习天数变化（+12% / -5% / →）
```

### 2. 学习热力图

```
类似 GitHub Contribution Graph / Strava Activity Heatmap
布局：列 = 周几（一～日），行 = 周（近 12 周）
每个格子：12px × 12px, 间距 3px
颜色：5 级（见配色方案）

交互：
  hover 格子 → tooltip "5月15日 · 3/3 tasks · Day 42"
  click 格子 → 进入对应 Day 详情

右侧：月份标签（5月、6月、7月）
底部：图例（Less → More, 5 色）
```

### 3. 阶段进度条

```
每行：阶段名 + 进度条 + 百分比
进度条：高 8px，圆角 4px
  背景：#1e2238
  填充：渐变 #4da6ff → #00d4aa
  已完成 → 纯色 #00d4aa
  进行中 → 渐变（从左到右越来越亮）
  未开始 → 纯背景色

右侧：百分比数字 + 天数 "12/12"
已完成阶段 → 绿色勾 ✓
进行中阶段 → 蓝色圆点 ●
未开始 → 灰色横线 —
```

### 4. 阶段时间轴

```
横向连线时间轴
节点：
  已完成 = 填充绿圆 ●（直径 12px）
  进行中 = 蓝色外圈 + 脉冲动画 ◉（直径 14px）
  未开始 = 空心灰圆 ○（直径 10px）

连线：
  已完成段 = #00d4aa 实线 2px
  未开始段 = #1e2238 虚线 1px

标签：节点下方小字 "阶段一" + "12天✓"
```

### 5. 日列表

```
可滚动的格子网格
每个格子：20px × 20px, 间距 4px, 圆角 3px
格内无文字（纯色块）
hover → tooltip "Day 42: 标题"
click → 进入详情
当前天（今天该做的）→ 蓝色边框高亮
```

### 6. 搜索框

```
位置：日列表右上角
样式：深色输入框，边框 #1e2238
placeholder："搜索 Day 编号或关键词..."
实时过滤日列表（输入时即时高亮匹配的格子）
```

### 详情页要点

- **大进度条**：页面顶部，比主页更醒目，作为"今日任务完成度"的核心视觉
- **元信息标签行**：小圆角标签，Day 编号 + Sync 关联（数学轨道特有）
- **任务列表**：用 `[✓]` `[ ]` 方括号标记（ASCII 风格，呼应量化/终端主题）
  - 完成项绿色 + 删除线
  - 整行可点击
- **底部时间线**：显示当前 Day 前后各 2 天，标注完成状态
  - 当前 Day = 蓝色高亮边框
  - 已完成 = 绿色圆点
  - 未完成 = 灰色圆点
  - 可点击跳转到相邻 Day
- **导航按钮**：分布在两端（左 ← 右 →），Home 居中

## 响应式行为

```
> 1024px：
  - KPI 5 列
  - 图表区 2 列（热力图 + 阶段进度）
  - 详情页 max-width: 800px

768-1024px：
  - KPI 3+2 折叠（前 3 个显示，后 2 个隐藏或折叠）
  - 图表区 1 列堆叠

< 768px：
  - KPI 横向滚动
  - 热力图缩小（8px 格子）
  - 时间轴变纵向列表
  - 日列表缩小

< 480px：
  - KPI 2 列 grid
  - 仅显示最关键的 4 个指标
  - 所有格子缩小到 8px
```

## 动画/过渡

```
- KPI 数字变化：CSS transition（数字上升/下降的微妙动画）
- 进度条填充：0.6s ease-out（加载时从 0 到目标值）
- 热力图格子 hover：scale(1.3) + 亮度提升，0.15s
- Prompt 展开/折叠：max-height 过渡 0.3s ease
- 时间轴脉冲：当前阶段节点的呼吸动画（opacity 1→0.5→1, 2s infinite）
- 页面切换：淡入淡出 0.2s
- 搜索过滤：格子用 CSS transition 隐藏/显示
```

## 特殊交互

| 交互 | 行为 |
|------|------|
| KPI 卡片点击 | 跳转到对应详情（如 Streak 点击 → 展开连胜日历） |
| 热力图 hover | 浮起 tooltip 显示当天详情 |
| 热力图 click | 进入对应 Day |
| 搜索过滤 | 实时高亮匹配的 Day 格子，非匹配项降低透明度 |
| 时间轴节点 click | 跳转到该阶段的第一个 Day |
| 进度条 hover | 显示详细 tooltip "已完成 18/23 天，预计 X 天完成" |
| 右键 KPI | 导出数据 JSON |
| 双击顶栏 | 回到今天该做的 Day |
